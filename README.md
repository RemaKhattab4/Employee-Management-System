# Nexora - Employee Management System

## About The Project

Nexora is a full-stack Employee Management System designed to simplify and organize employee operations within an organization.

The system provides an easy-to-use dashboard for managing employee records, departments, and attendance, while allowing administrators to monitor and organize employee information efficiently.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- HTML
- CSS
- JavaScript
- REST APIs
- Maven

## Main Features

- Employee Management (CRUD operations).
- Add, update, view, and delete employee records.
- Department Management.
- Attendance Management.
- Dashboard for displaying system information.
- Database integration using MySQL.
- Organized backend architecture using Controller, Service, and Repository layers.
